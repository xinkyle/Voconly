# Changelog

## [0.5.3] - 2026-09-02

### 优化
1. **应用图标圆角化处理**，统一任务栏、托盘和桌面快捷方式图标样式，使用高质量 Lanczos3 算法生成多尺寸图标。

2. **添加 Gitee 发布支持**，新增自动上传脚本，支持将版本发布到 Gitee 平台。

3. **更新检查优化**，添加 GitHub raw 作为备用更新源，提高更新检查成功率。

4. **Demo 文件格式优化**，将 GIF 格式替换为 WebP 格式，提升加载速度和画质。

# Changelog
