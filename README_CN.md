# Voconly — 语音进，文字出，搞定。

**自然地说话，Voconly 在本地完成转录、用 AI 润色，并把成品文字直接送到你的光标处——在任何应用中。**

无云端。无额度限制。无需复制粘贴。

## 你的思绪，比手指快得多

说话是本能，打字却很慢。大多数灵感，都死在这两者之间的空隙里。

Voconly 填平了这个空隙——尽情地说，让 AI 负责整理。

---

## 大多数语音工具止步于"转文字"，Voconly 不止于此。

传统语音工具把语音变成一段转录稿——然后你复制、粘贴、再编辑。

Voconly 把语音变成**成品文字**。

 **自然地说话**
↓
 **本地转录**
↓
 **AI 理解并润色**
↓
 **成品文字出现在你的光标处**

不用切换窗口。不用复制粘贴。文字直接落在你正在输入的地方。

**两种结束方式，一键完成：**

- **按一下开始 → 再按一下结束：** 完整流程，输出 AI 润色后的文字
- **按一下开始 → 双击结束：** 跳过 AI，直接输出原始转录

---

## 同一条嗓子，不同的意图。

同一句话，可以有完全不同的用途——一个随手的想法、一封正式的邮件、一段翻译、一份会议纪要。

为每种工作流指定一个快捷键，一键切换模式。

| 模式 | 你说的是…… | 你得到的是…… |
|---|---|---|
| 📝 快速记录 | "呃就是那个方案我觉得可以再改改……" | 修正错别字、整理标点，原意不变 |
| 💼 专业润色 | 口语化的碎碎念 | 结构清晰、表达专业的书面文字，保留核心思想 |
| 🌐 翻译 | 中文（或英文） | 另一种语言直接出现在光标处——支持你的 LLM 所支持的任何语言 |
| 🗂️ 会议秘书 | 会议讨论 | 带要点的结构化纪要 |
| 🛠️ 自定义 | 任何内容 | 你自己的提示词，你自己的处理逻辑 |

每种模式拥有自己的**快捷键和处理提示词**，而 ASR 模型和 LLM 供应商在所有模式间通用。

> 按下设定的键开始说话，再按一次即可结束。

## 为日常使用而生

**⚡ 边说边见文字**
无论使用哪种 ASR 模型，Voconly 都能给你带来实时的转录体验。说话时文字逐句出现——说完的那一刻，结果已经就绪。没有转圈等待，没有尴尬的停顿。

**♾️ 长时间连续口述，也能保持稳定转录**
无论说几分钟还是几小时，Voconly 都针对长时转录进行了优化，避免随着录音持续时间增加而出现明显的准确度衰减。

**📍 只要能打字的地方，就能用 Voconly**
浏览器、Word、Notion、VS Code、微信、邮箱客户端——只要能打字，Voconly 就能工作。

## 为什么选择 Voconly？

|  | Voconly | 传统听写工作流 |
|---|---|---|
| 🔒 隐私 | 语音绝不出你的设备 | 经常被上传到云端 |
| ♾️ 限制 | 开源 + 本地运行 + 没有云端额度 | 免费额度或订阅制 |
| ✨ 输出 | 成品级润色文字 | 原始转录稿 |
| 🔁 流程 | 直接出现在光标处 | 复制 → 粘贴 → 编辑 |
| ⏱️ 长时使用 | 数小时保持稳定 | 准确度可能随时间下降 |
| 🧩 模型 | 自由选择喜欢的模型 | 被锁定在单一服务商 |

## 使用你喜欢的模型

你不必被绑定在某一家 AI 服务商上。可以选择完全本地的工作流，也可以接入你喜欢的云端模型。

- **语音识别（ASR）：** Whisper · SenseVoice · Parakeet · Qwen-ASR
- **大语言模型（LLM）：** Ollama（本地）+ 主流云端 API 服务商

## 60 秒上手

1. **下载** Voconly → [Releases](https://github.com/xinkyle/Voconly/releases)
2. **启动**——选择一个推荐模型
3. **按下快捷键开始说话**——再按一次输出润色文字，双击输出原始转录

就这么多。

**从源码构建（Windows）：**

```powershell
.\setup.ps1        # 检查并安装依赖
.\start-dev.ps1    # 启动开发服务器
没有 GPU / 不想装 Vulkan SDK？使用 .\setup.ps1 -SkipVulkan（CPU 模式）。建议使用 GPU 以获得最佳速度。
```

### 为何开源？

我构建 Voconly 是因为我想要一个真正属于自己的语音工具：

-   没有订阅配额
    
-   默认不上传任何音频
    
-   不依赖单一公司
    
-   没有我无法控制的黑盒
    

所以我把它开源了。

Voconly 也是我关于“今天一个人 + AI 能构建出什么”的一次实验。如果它对你有帮助，一颗 ⭐ 对我意义重大。
