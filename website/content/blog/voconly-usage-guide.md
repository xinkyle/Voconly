## 什么是 Voconly？

Voconly 是一款本地优先的 AI 语音输入助手，它将语音转文字与大语言模型（LLM）后处理能力结合，帮助你用语音高效完成文字输入。无论是会议记录、邮件撰写还是日常笔记，Voconly 都能将你的口述内容智能转换为结构化文字。

核心价值在于：完全离线可用，所有处理都在本地完成，保护隐私安全；全局快捷键随时触发，不依赖网络连接；实时转写让你即时看到识别结果。这篇指南将从零开始，带你完成安装、配置并掌握高效使用技巧。

## 安装与启动

### 下载地址

- GitHub Releases: https://github.com/xinkyle/Voconly/releases
- 官网下载: https://www.voconly.com

选择最新版本的安装包下载即可。

### 系统要求

- 操作系统：Windows 10/11
- 硬件：推荐配备 GPU（NVIDIA 显卡）以获得更快的转写速度，无 GPU 也可使用 CPU 模式

### 首次启动

安装完成后首次启动，Voconly 会引导你完成基础配置：
1. 选择 ASR（语音识别）模型
2. 设置全局快捷键
3. （可选）配置 LLM 服务

整个流程简洁直观，通常几分钟即可完成。

## 模型配置

### ASR 模型选择

Voconly 支持多种 ASR 模型，推荐新手从以下选项开始：

- **SenseVoice Small**: 中文识别效果出色，响应速度快，适合纯中文场景。

如果对识别精度要求更高，尤其是中英文混合转录场景，建议qwen-asr 1.7b 模型，但需要更多显存和计算资源。系统默认下载的是Q5的量化版，作为性能和效果均衡考虑。

如果你本地有GPU，内存也充盈，建议访问下面两个网站：
中文访问魔搭社区：https://www.modelscope.cn/profile/voconly
英文访问huggingface：https://huggingface.co/voconly
下载模型更多量化版本：
通常F16 > Q8 > q5 > q4
越靠前模型越大，占用资源越多，看本地资源而定。 

模型下载后可以放置到默认位置，
也可以放置到自定义位置，通过模型进入模型列表，在语音转文本模型卡片中有一个导入外部模型按钮，点击后添加模型所在目录即可使用。每个模型默认使用最高量化版本，如果同时有Q5和Q8版本，选择该模型时会默认使用Q8版本。

### 模型下载

首次选择模型时，Voconly 会根据语言选择自动从 HuggingFace或者魔搭社区 下载选中模型。下载进度会在界面上显示，请耐心等待。模型会缓存在本地，后续使用无需重复下载。

### LLM 配置（可选）

LLM 用于对转写结果进行润色、翻译或生成会议纪要。你可以选择：

**本地方案：**
- Llama.cpp：直接加载本地 GGUF 模型
- Ollama：通过 Ollama 运行本地模型

**云端 API：**
- OpenAI、DeepSeek、Qwen、Claude、智谱 AI 等

在设置页面填入对应 API 密钥即可启用。如果暂时不需要 LLM 功能，可以跳过此步骤。

## 快捷键设置

### 如何设置

在设置界面找到「快捷键」选项，点击输入框后按下你想使用的按键。支持：

- **单键**：F1-F12、数字键、字母键等

### 使用技巧

- **正常模式**：按下快捷键开始录音，这个时候会实时转写，再次按下快捷键开始处理剩下的语音，如果配置了LLM（大模型）则交给大模型处理，按照选择的提示词进行大模型处理，返回结果。
- **跳过 LLM**：双击快捷键（快速按两次），只进行转写，不经过 LLM 处理（即便场景配置了LLM也会跳过LLM），适合快速输入不需要润色的内容

快捷键全局生效，在任何应用中都能使用。

## 场景配置

### 什么是场景化配置

场景是一组预设的 LLM 提示词和处理规则。不同场景下，同样的语音内容会被处理成不同风格的结果。比如「会议记录」场景会生成结构化纪要，而「邮件撰写」场景会生成正式的邮件格式。

### 推荐场景示例

1. **会议记录**：将口述内容整理成会议纪要，自动提取关键议题和待办事项
2. **邮件撰写**：将口语化输入转换为正式邮件格式，自动组织段落
3. **简单润色**：对转录结果做简单润色处理，错别字，不对的表达，标点符号，保持原来的口语化感觉。
4. **专业润色**：对转录结果进行更正式的处理，会基于原来意思做重新表达，得到逻辑清晰的结果

### 如何自定义场景

在场景设置页面点击「新建场景」，输入场景名称和提示词即可。系统提供了默认提示词，也支持用户自定义提示词。

## 使用技巧

### 实时转写体验

Voconly 支持实时转写，按下快捷键后可以看到文字实时出现在屏幕上。这让你能够即时确认识别结果，发现错误可以马上调整语速或重新表述。

### 获得最佳识别效果

- **麦克风质量**：使用降噪效果好的麦克风，避免环境噪音干扰。内置麦克风也可以使用，但在嘈杂环境下效果会下降
- **说话清晰度**：保持正常语速，吐字清晰。过快或含糊会增加识别错误
- **距离适中**：嘴巴距离麦克风 10-30 厘米为宜
- **环境安静**：在安静环境下识别率更高

### 常见问题处理

- **识别率低**：检查麦克风是否正常工作，尝试更换更大的模型
- **转写速度慢**：如果有 GPU，确保驱动已正确安装；或尝试使用更小的模型
- **LLM 处理慢**：本地模型需要更多显存，或者更换为云端API处理

## 总结

Voconly 将离线语音识别与智能文本处理结合，让你用语音高效完成各类文字输入任务。从安装启动、模型选择到快捷键和场景配置，这篇指南涵盖了核心使用流程。建议从 SenseVoice Small 或者qwen asr 1.7b开始，逐步探索适合自己的使用方式。下载 Voconly，用声音释放你的生产力。
